# Usage score

How much fantasy opportunity a player got in a week, as a 0–100 percentile
that compares across positions: a WR's 70 and an RB's 70 mean the same
amount of opportunity. Built for simple mode's "Usage score" chart.

Status: calibrated, running client-side in the admin-only Simple mode
sandbox (`src/lib/usageScore.ts`). Not yet server-side.

## Method

1. **Value each opportunity in expected fantasy points (xFP).** Carries,
   targets, red-zone carries and targets (and for QBs, pass attempts and
   red-zone attempts) are weighted by how many points each is worth on
   average, fit by least squares (no intercept) against real weekly points.
   One weight set covers RB/WR/TE - per-position weights predicted no
   better (within 0.01 R²), so a carry is worth the same to anyone, which
   is what makes the score comparable across positions.
2. **Read xFP as a percentile.** Against each week's top 172 RB/WR/TE
   player-weeks by xFP (60 RB + 80 WR + 32 TE, pooled over the baseline
   seasons). QBs are read against each week's top 32 QBs instead - against
   flex players nearly every QB lands in the 80s-90s.
3. **Split the stacked bars by share.** The total is the percentile; the
   rushing / receiving / passing segments split it by each part's share of
   the week's xFP, so the stack adds up.

Weights and percentile tables are generated by
`scripts/usage-calibration/calibrate.py` into `src/lib/usageCalibration.ts`,
for every scoring setup a league can have: STD / HALF / PPR, TE premium
(NONE / HALF / FULL - an extra weight on a TE's targets), and 6-point
passing TDs (QB weights). The league's own setup is applied when the score
is read - never added as a dimension to the shared season scoring config.

**Re-calibrate once a season**, in the offseason: bump `BASELINE_SEASONS`
(last 3 completed seasons) and re-run. Freezing the baseline for the season
keeps a week's score from drifting as new weeks arrive.

## Calibration results (2023-2025, holdout = 2025)

Half PPR, no TE premium: points per carry 0.46, red-zone carry +0.83, target
1.24, red-zone target +1.14 - a target is worth ~2.7 carries. Targets move
with PPR (0.90 STD → 1.57 PPR); carries barely do. TE premium adds +0.35
(HALF) / +0.71 (FULL) per TE target.

| Model | Holdout R² |
|---|---|
| RB/WR/TE, STD / HALF / PPR | 0.61 / 0.67 / 0.72 |
| QB (4-pt / 6-pt pass TDs) | 0.59 / 0.54 |

Weights are stable season to season (half-PPR target 1.22-1.25, carry
0.43-0.48), and holdout xFP tracks actual points in every decile. The
unexplained rest is efficiency and touchdown variance, which a usage score
shouldn't capture.

Example weeks, half PPR (percentile, RB/WR/TE):

| Score | Week |
|---|---|
| 99 | RB, 25 car (5 RZ), 6 tgt (1 RZ) |
| 90 | RB, 18 car (3 RZ), 4 tgt |
| 84 | WR, 10 tgt (1 RZ) |
| 67 | RB, 3 car, 7 tgt |
| 64 | TE, 7 tgt (1 RZ) |
| 54 | RB, 15 car (2 RZ), 0 tgt |
| 11 | WR, 3 tgt |

## What was ruled out, and why

- **Air yards.** Sleeper's `rec_air_yd` / `pass_air_yd` count completed
  passes only (air yards + YAC == receiving yards) - a result, not an
  opportunity. (The game log's "Air" column is completed air yards too.)
- **Snaps, snap %, team snaps, target / carry / red-zone share, team pass
  attempts.** Together +0.005 R² for describing a week: once carries and
  targets are counted, being on the field adds nothing. They matter for
  predicting the *next* week - see below.
- **A starter / flex line on the chart.** The borderline starter's usage
  ranges from about the 40th to the 80th percentile week to week, and the
  starter and flex lines landed within a few points of each other - noise.

## Future: next week's projected usage

A forward-looking score ("how much work will he get?") is a different model
from this one. Findings so far, predicting next week's half-PPR points from
this week:

| Inputs | Next-week R² |
|---|---|
| Carries, targets, red-zone looks | 0.339 |
| + snap % | 0.365 (+0.026) |
| + snaps | 0.356 (+0.017) |
| + target share / carry share | 0.348 / 0.346 |
| + all of the above | 0.373 (+0.035) |

To make it better:

1. **Use snap % and target / carry share** - unlike in the weekly score,
   they carry real signal forward (snap % alone is the biggest single gain).
2. **Use several weeks, not one** - a weighted trailing average (recent
   weeks heavier) of xFP, snap %, and shares. Untested, but a single week
   is noisy and this is likely the biggest gain available.
3. **Add data Sleeper doesn't have** (nflverse play-by-play, free):
   intended air yards / aDOT (a deep target is worth more than a screen)
   and inside-the-5 carries (goal-line role). Routes run / route
   participation is the strongest known WR predictor but mostly comes from
   paid sources.
4. **Adjust for context** - injuries to teammates (vacated targets and
   carries), the depth chart (`depthCharts`), and the injury outlook's
   availability / limitation for the player himself.
5. **Validate the same way** - fit on prior seasons, test on a held-out
   season, check calibration by decile.
